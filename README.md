# Homework #3 — Data Loading and SQL Basics (DQL)

Importing 8 CSV tables into MySQL and writing DQL queries: SELECT, aggregate functions, DISTINCT, ORDER BY, LIMIT, WHERE BETWEEN, GROUP BY.

## Files
- `queries.sql` — all SQL queries for tasks 1–5
- `p1a_select_products.png` — Task 1a: SELECT * FROM products
- `p1_select_shippers.png` — Task 1b: SELECT name, phone FROM shippers
- `p2_aggregates.png` — Task 2: AVG / MAX / MIN price
- `p3_distinct_top10.png` — Task 3: DISTINCT category_id, price (top 10 by price)
- `p4_price_range_count.png` — Task 4: product count with price between 20 and 100
- `p5_supplier_stats.png` — Task 5: product count and average price per supplier

## Dataset
8 tables imported from CSV: `categories`, `customers`, `employees`, `order_details`, `orders`, `products`, `shippers`, `suppliers`.
